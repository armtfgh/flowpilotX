# Check-valve icon

Place the supplied icon in this folder as **check_valve.png** (lowercase).
The shared flowsheet renderer checks for it on each new render; no further
code change is needed after adding the file.

Use a square PNG, preferably at least 512 x 512 pixels, on a transparent or
white background. Orient any flow-direction symbol left to right. Keep the
symbol centered with modest padding. Do not bake equipment model numbers,
pressure values or flow rates into the image; those remain in the caption.

Until the file is supplied, a labeled check-valve box remains visible. No
unrelated equipment icon is substituted. Already exported images are unchanged
until explicitly rendered again.
